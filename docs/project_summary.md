# Project Summary

## 프로젝트명

전월세 데이터 분석 및 임대료 예측

## 한 줄 설명

서울 전월세 실거래 데이터를 기반으로 임대료에 영향을 주는 변수를 분석하고, 회귀 모델을 통해 가격 예측 가능성을 확인한 데이터 분석 프로젝트입니다.

## 문제 정의

전월세 가격은 자치구, 면적, 건물용도, 건축년도, 계약 유형 등 다양한 요인에 의해 달라집니다. 이 프로젝트는 대규모 실거래 데이터를 정제하고 주요 변수를 분석해 임대료 예측 모델을 구성하는 것을 목표로 합니다.

## 사용 데이터

- 전세 처리 데이터: `seoul_final_processed_jeonse.csv`
- 월세 처리 데이터: `seoul_final_processed_wolse.csv`

데이터 파일은 GitHub에 업로드하지 않고 로컬 또는 별도 저장소에 보관합니다.

## 주요 작업

- 전월세 데이터 전처리
- 전세/월세 데이터 분리
- 파생 변수 생성
- EDA
- 회귀 모델 학습
- 모델 성능 평가
- 보고서 작성

## 포트폴리오에서 강조할 점

- 대용량 실거래 데이터 처리 경험
- 데이터 정제 및 파생 변수 생성
- 회귀 모델 비교 및 평가
- 분석 결과를 보고서로 정리한 경험
